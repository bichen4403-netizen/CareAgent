# 智护同行

**基于多智能体协同的老年人全流程智能陪诊系统** · 2026 中国高校计算机大赛 AI 创意赛 · 鸿蒙赛道

老人只说一句“明天上午去市第一人民医院复查血压”，系统就把挂号方案、出发时间、院内路线和全流程提醒一次安排好；看完病记下复诊间隔，到期前再主动提醒。

> 当前版本 v1.1，相比上一版的全部改动、替换清单和删除清单见 [CHANGELOG.md](CHANGELOG.md)。

## 一、快速运行

### 1. 离线演示模式（默认，零配置）

1. DevEco Studio → Open，选择本工程根目录，等待 Sync 完成。
2. 如果提示 SDK 版本不匹配，把根目录 `build-profile.json5` 的 `compatibleSdkVersion` / `targetSdkVersion` 改成本地已安装的版本。
3. 选择手机或平板（真机 / 模拟器）运行。
4. 进入“我的 → 演示工具 → 恢复演示数据”，回到首页会出现“复诊时间快到了”的主动关怀卡片。

离线模式下，语义理解使用端侧规则，号源、天气、路况使用演示数据，并在界面上标注“演示 / 估算”。**答辩现场断网也能完整跑通。**

### 2. 连接网关（真实大模型 + 高德）

1. 按 [backend/README.md](backend/README.md) 启动网关，在 `backend/.env` 填 `LLM_API_KEY`（DeepSeek）和 `AMAP_API_KEY`（高德「Web服务」类型 Key）。模型名用 `deepseek-flash`，旧名 `deepseek-chat` 已停用。
2. 修改 `entry/src/main/ets/config/BackendConfig.ets`：
   - `BASE_URL`：模拟器填 `http://10.0.2.2:8000`；真机填电脑的局域网地址，如 `http://192.168.1.8:8000`；正式环境必须用 HTTPS。
   - `APP_TOKEN`：与 `.env` 的 `APP_ACCESS_TOKEN` 相同；网关没设就留空。
3. 重新运行。首页副标题变成“已连接大模型”，陪诊安排里的天气、车程会标注“实时”。

客户端不保存任何第三方密钥。网关不可用时自动退回离线规则，并如实标注数据来源。

### 3. 设备说明

- App 安装在**手机 / 平板**（`module.json5` 中 `deviceTypes` 为 phone、tablet）。
- 手表**不需要安装本应用**：全流程提醒走系统代理提醒，系统通知会按用户设置同步到已配对的手表 / 手环（在手机“运动健康”App 的设备设置里打开本应用的消息通知）。
- 耳机：院内引导逐步语音播报，连着蓝牙耳机时从耳机出声。

## 二、一次完整陪诊

```
说一句话 → 理解需求（缺什么只问什么）→ 四个 Agent 协同出方案 → 查看陪诊安排
  → 去官方渠道挂号 → 回来点“我已挂上号” → 系统提醒就位、桌面卡片随时间前进
  → 到医院打开院内引导 → 看完病记下复诊间隔 → 到期前 3 天主动提醒复诊
```

| 环节 | 老人看到什么 | 背后做了什么 |
|---|---|---|
| 说需求 | 点“点我说话”，说完再点一下；也可以打字或点例句 | 系统语音识别，边说边出字；网关不可用时用端侧规则理解 |
| 补信息 | 缺医院、科室或日期时一次只问一项，下方给出可点的候选 | 多轮槽位补全，最多追问 4 轮，10 分钟未回答自动作废；“算了不去了”随时取消；说成已过去的日期会提醒改期 |
| 出方案 | 进度面板四个 Agent 依次完成，语音播报摘要 | 医疗 → 出行 / 导航并行 → 提醒汇总（见第三节） |
| 看方案 | “陪诊安排”页：就诊、出行、院内路线、出门准备、全流程提醒 | 每项数据标注来源；方案只是推荐，不等于已经挂号 |
| 去挂号 | 点“去‘浙里办’确认挂号”，按所在城市跳转本地官方渠道 | 方案持久化在本机，跳走后 App 被系统回收也不会丢 |
| 开提醒 | 回来点“我已挂上号，开启提醒” | 注册系统代理提醒，点提醒直达对应页面 |
| 路上 | 桌面卡片显示“下一步做什么” | 卡片每次刷新都按当前时间重新计算 |
| 到医院 | “院内引导”一步一个大字卡片，并语音播报 | 按楼层生成路线；取药会追加去药房的路线 |
| 看完病 | 就诊 2 小时后首页问“医生让您多久后复查？”，点一下即可，也可以拍处方单 | 写入本机病历；到期前 3 天主动提醒，可一键重新安排 |

对话里还可以：

- 问行程：“我几点出发？”“要带什么？”“诊室在几楼？”“那天天气怎么样？”
- 紧急情况：说“胸口疼、喘不上气”等，立即引导拨打 120，不做任何诊断；“帮我打给我女儿”一键拨打紧急联系人。
- 查报告：引导到官方渠道或医院自助机查询，拿到单子后拍照录入。
- 点任意一条对话气泡可以再听一遍。

### 2. 多智能体协同

```
                   ┌──→ T2 出行（读 T1 的就诊时间和医院位置，倒推出发时间）──┐
T1 医疗 ───────────┤                                                          ├──→ T4 提醒
（定医院/医生/时段）└──→ T3 导航（读 T1 的楼层和诊室，规划院内路线）────────┘  （读 T1/T2/T3 的全部时间点）
```

T2、T3 并行执行。出行 Agent 不自己决定就诊时间，而是从共享黑板读取医疗 Agent 的结果；提醒 Agent 汇总前三者的时间点。

**出发时间** = 就诊时间 − 车程 − 预留时间，再向下取整到 5 分钟，方便老人记。预留时间以取号排队的 20 分钟为基础：小雨雪、雾霾 +10，暴雨、大雪等恶劣天气 +25，缓行 +5，拥堵 +15。按建议时间已经来不及时，会直接提示“现在就打车出发”或去官方渠道改约。

**全流程提醒**（相隔不到 5 分钟的合并，已过去的自动跳过）：

| 时间 | 内容 | 设备 |
|---|---|---|
| 就诊前一晚 20:00（离得太近则改为出发前 60 分钟） | 备好证件、医保卡、病历和药盒 | 手机 |
| 出发前 20 分钟 | 准备出门，带伞 / 打车提示 | 手表 |
| 出发时间 | 该出发了 | 手表 |
| 预计到院时间 | 打开院内引导 | 耳机 |
| 就诊前 10 分钟 | 到诊室门口候诊，留意叫号 | 手表 |
| 看完病后 | 取药：按新处方吃药；看病：记录医生让多久后复查 | 手机 |

### 3. 异常回流与重规划

- **医生临时停诊**：只重跑医疗及其下游（出行、导航、提醒），新方案自动避开停诊医生。
- **就诊日恶劣天气**：只重跑出行和提醒，挂号和院内路线不变；加大预留时间并建议打车。
- 同一次安排最多重规划 2 次。部分环节失败时如实播报“只完成了部分安排”，不会说“都安排好了”。
- 演示时打开“我的 → 演示工具”里的两个开关即可稳定触发。

### 4. 端侧记忆与主动关怀

- 病历来源：看完病后的一键回答、拍处方单识别（本人核对后才保存）、手动录入。
- 复诊到期前 3 天（逾期 7 天内），首页出现提醒卡片并播报，每天最多一次；可以选“帮我安排 / 以后再说 / 不用复诊”。
- 说“复诊”时默认沿用上次的医院和科室；没说医院时优先推荐常去的医院；取药时带出上次处方供医生参考。

## 五、答辩演示脚本（约 5 分钟）

演示前：“我的 → 演示工具 → 恢复演示数据”，两个模拟开关先关闭；在桌面添加“智护同行”服务卡片。联网、断网均可。

1. **主动关怀**（30 秒）：打开 App，首页“复诊时间快到了”卡片自动播报。点“帮我安排”，直接生成复诊方案。要点：从“等指令”到“主动陪伴”。
2. **一句话全流程**（60 秒）：点“点我说话”，说“明天上午去市第一人民医院复查血压”。进度面板里四个 Agent 依次完成：医疗定号源 → 出行和导航并行 → 提醒汇总。
3. **方案与确认**（60 秒）：点“查看完整安排并确认”。讲数据来源标注和“推荐不等于已挂号”；点“去‘浙里办’确认挂号”跳官方渠道，返回后点“我已挂上号，开启提醒”（现场没有官方 App 时点“已经挂好了？直接开启提醒”）。回桌面看卡片。
4. **追问**（20 秒）：问“我几点出发？”“要带什么？”
5. **异常重规划**（60 秒）：在“我的”打开“模拟医生临时停诊”和“模拟就诊日暴雨”，回首页说“下周三去市第一人民医院看眼科”。听播报：停诊自动换医生，暴雨加大预留并建议打车。要点：只重跑受影响的子图。
6. **院内引导**（30 秒）：陪诊安排 → 开始院内引导，逐步大字 + 语音。
7. **闭环与安全**（30 秒）：点“拍病历”识别处方单（模拟器上用“手动录入”）；说“我胸口疼得厉害”演示 120 引导。看完病的复诊询问在就诊 2 小时后才会出现，现场口头说明即可。

## 六、安全与合规边界

- 不做诊断，不给用药建议；用药提醒只复述处方单上已有的内容；识别到急症词直接引导拨打 120。
- 系统只生成**推荐方案**，挂号必须由本人在医院官方渠道完成；页面始终提示以官方渠道的挂号结果为准。
- 档案、病历、行程只保存在本机；发给大模型的内容不含姓名、住址和医生姓名；用户原话加边界标记，防止提示词注入。
- “我的”页可以删除单条病历，也可以一键清除全部数据。
- 第三方密钥只放在网关；网关支持访问令牌和限流，错误信息经过脱敏。
- 所有展示数据都标注来源，演示和估算数据不会冒充实时数据。

## 八、常见问题

- **首页一直显示“离线演示模式”**：`BackendConfig.BASE_URL` 为空，或网关不可达。用浏览器打开 `BASE_URL/health` 检查。
- **真机连不上网关**：用电脑的局域网 IP 而不是 `127.0.0.1`；手机和电脑连同一个 Wi-Fi；电脑防火墙放行 8000 端口。
- **没有语音 / 识别不可用**：模拟器通常没有语音引擎，可以打字或点例句；真机检查麦克风权限。
- **提醒没有弹出**：检查系统通知权限。开启提醒时如果通知没打开，“陪诊安排”页会提示。
- **手表没收到提醒**：在手机“运动健康”App 的设备设置里打开本应用的消息通知。
- **小艺技能**：`entry/skills/*/scripts/*.ets` 每个脚本都自包含，按各自 SKILL.md 的“上传说明”上传；travel-plan 脚本顶部可以填网关地址。
